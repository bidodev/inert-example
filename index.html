Why this combination
<dialog> alone
Handles the modal — renders above content, manages the backdrop, supports showModal() / close() natively.
inert alone
Freezes any element's subtree — no clicks, no tab navigation, screen readers skip it. One attribute, zero JS event soup.
Together
Dialog gets all focus. Page behind becomes completely unreachable. Keyboard, pointer, and assistive tech all agree.
vs. old patterns
No pointer-events: none hacks, no manual focus traps, no aria-hidden juggling. Native, accessible, ~94% browser support.
